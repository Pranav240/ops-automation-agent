# Refund destination and payment methods

Refunds go only to the original payment method used for the order (card or PayPal).

Agents cannot send refunds to a different card, a different PayPal account, a bank transfer, cash, cryptocurrency, or another person. If a customer asks for a different destination, decline that part and explain the refund can go only to the original payment method.
