# Order status definitions

- placed: order received, payment taken, not yet picked.
- processing: being picked and packed.
- on_hold: paused at the customer's request (POL-011).
- shipped: handed to the carrier; tracking is active.
- delivered: carrier confirmed delivery.
- cancelled: cancelled before shipping; fully refunded.
- refunded: fully refunded after delivery.

Agents can set only these statuses: "cancelled", "on_hold", and "processing" (to release a hold). Agents cannot mark orders as shipped, delivered, or refunded.
